# 平台同步配置指南

## 概述

系统支持将文章一键同步到多个技术社区平台。凭据通过后端**环境变量**配置，启动时自动加载。

| 平台 | 状态    | 配置方式 |
|------|---------|----------|
| 博客园 (CNBLOG) | ✅ 可用 | 个人访问令牌 (PAT) + REST API |
| 掘金 (JUEJIN) | ❌ 不可用 | Cookie 式 token 已过期/失效 |
| CSDN | ⚠️ stub | 无公开 API，待研究 |
| 思否 (SEGMENTFAULT) | ⚠️ stub | 无公开 API，待研究 |

---

## 快速配置（所有平台）

凭据通过 **环境变量** 注入，无需进入后台填写。以 `PLATFORM_{CODE}_{FIELD}` 格式命名：

```bash
# 博客园（唯一可用的平台）
PLATFORM_CNBLOG_PERSONAL_TOKEN=<你的PAT>
```

所有平台的 api-url 有默认值（见 `application.yml`），如需覆盖同样通过环境变量：

```bash
PLATFORM_CNBLOG_API_URL=https://i.cnblogs.com/openapi/v1/posts
```

## 博客园 (CNBLOG) ✅ 可用

### 同步方式

通过博客园官方 **OpenAPI**（REST 风格）发布文章。

- **API**: `POST https://i.cnblogs.com/openapi/v1/posts`
- **认证**: `Authorization: Bearer <PAT>` + `Authorization-Type: pat`

### 如何获取 PAT（个人访问令牌）

1. 登录 [博客园](https://www.cnblogs.com/)
2. 进入设置 → **个人访问令牌**（或访问 `https://i.cnblogs.com/settings#pat`）
3. 点击 **创建令牌**
4. 填写令牌描述（如 `djblog-sync`）
5. 作用域至少选择 **`post:write`**（发布文章权限）
6. 创建后 **立即复制保存**（令牌只在创建时显示一次）

### 配置方式

```bash
# 环境变量（推荐）
PLATFORM_CNBLOG_PERSONAL_TOKEN=your_personal_access_token_here
```

或在 `application.yml` 中：

```yaml
platform:
  cnblog:
    personal-token: your_personal_access_token_here
    api-url: https://i.cnblogs.com/openapi/v1/posts
```

### 请求格式

```json
{
  "title": "文章标题",
  "body": "文章内容（Markdown 格式）",
  "postType": "BlogPost",
  "postFormat": "Markdown",
  "description": "文章摘要（可选）",
  "slug": "url-slug（可选）",
  "isPublished": true,
  "isAllowComments": true
}
```

| 字段 | 说明 |
|------|------|
| title | 文章标题 |
| body | Markdown 正文，系统会自动追加原文链接 |
| postType | 固定为 `BlogPost` |
| postFormat | 固定为 `Markdown` |
| description | 文章摘要（可选） |
| slug | URL 别名（可选） |
| isPublished | 是否直接发布 |
| isAllowComments | 是否允许评论 |

### 响应格式

```json
{
  "success": true,
  "message": "操作成功",
  "value": {
    "postUrl": "https://www.cnblogs.com/username/p/12345",
    "postId": 12345
  }
}
```

`success` 为 `true` 表示成功，否则 `message` 中包含错误描述。

### 注意事项

- PAT 个人访问令牌不会过期，但可以随时撤销
- 相比原来的 MetaWeblog (XML-RPC) 方式，PAT 更安全（可撤销、可限定作用域）
- 替换旧配置后，记得清除 `PLATFORM_CNBLOG_USERNAME` / `PLATFORM_CNBLOG_PASSWORD` 等旧环境变量

## 掘金 (JUEJIN) ❌ 不可用

### 现状说明

掘金目前**不可用**。之前的实现通过从浏览器 Cookie 中提取 `x-juejin-token` 进行认证，但这种 token 有有效期，过期后需要频繁重新获取，且掘金官方未提供长期有效的 API 凭据方案。

### 同步方式（过时参考）

之前通过掘金官方内容 API 发布文章：

- **API**: `POST https://api.juejin.cn/content_api/v1/article/publish`
- **认证**: `X-Juejin-Token` 请求头（从 Cookie 中提取）

### 如需恢复接入

需要调研以下方案之一：

1. 掘金是否开放了新的官方发布 API
2. 是否有长期有效的 token 方案
3. 或通过模拟浏览器操作的方式实现

### 配置示例（仅作参考，当前无效）

```bash
PLATFORM_JUEJIN_ACCESS_TOKEN=<从Cookie中提取的x-juejin-token>
```

## CSDN

### 同步方式

目前为 **stub 实现**（模拟成功返回，不真正调用 API）。

### 现状说明

CSDN 开放平台 (`https://api.csdn.net/`) 已停止新应用申请，目前没有官方公开的第三方文章发布 API。如需接入 CSDN，需要：

1. 研究 CSDN 的私有/内部 API
2. 或通过模拟浏览器操作的方式实现（需处理登录态、验证码等）
3. 或等待 CSDN 重新开放开放平台申请

### 配置示例（预留）

```bash
PLATFORM_CSDN_ACCESS_TOKEN=xxx
```

> 当前配置仅用于校验格式，实际不会发起同步请求。

## 环境变量完整列表

| 环境变量 | 对应配置 | 说明 |
|----------|----------|------|
| `PLATFORM_CNBLOG_PERSONAL_TOKEN` | `platform.cnblog.personal-token` | 博客园个人访问令牌 |
| `PLATFORM_CNBLOG_API_URL` | `platform.cnblog.api-url` | 博客园 API 地址（有默认值） |
| `PLATFORM_JUEJIN_ACCESS_TOKEN` | `platform.juejin.access-token` | 掘金 token（当前不可用） |
| `PLATFORM_JUEJIN_API_URL` | `platform.juejin.api-url` | 掘金 API 地址（有默认值） |
| `PLATFORM_CSDN_ACCESS_TOKEN` | `platform.csdn.access-token` | CSDN token（预留） |
| `PLATFORM_CSDN_API_URL` | `platform.csdn.api-url` | CSDN API 地址（有默认值） |
| `PLATFORM_SEGMENTFAULT_ACCESS_TOKEN` | `platform.segmentfault.access-token` | 思否 token（预留） |
| `PLATFORM_SEGMENTFAULT_API_URL` | `platform.segmentfault.api-url` | 思否 API 地址（有默认值） |

## 日志排查

同步时会打印以下日志辅助排查：

### 同步前（请求体）

```
INFO  - 同步文章到博客园: xxx
INFO  - 请求体: POST https://i.cnblogs.com/openapi/v1/posts
{ "title": "...", "body": "...", ... }
```

### 同步结果

```
INFO  - 博客园同步成功: https://www.cnblogs.com/username/p/12345
WARN  - 博客园同步失败: xxx
ERROR - 博客园同步异常
```

### 添加 DEBUG 日志

在 `application.yml` 中：

```yaml
logging:
  level:
    site.dengwei.blog.service.platform: debug
```
